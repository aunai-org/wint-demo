wint demo

When can you do it, for how long, and why? Give wint a plan of limits and a table of readings; it finds the time windows that stay inside your limits and shows its evidence. The first example uses weather forecasts; the Example menu shows the same engine on other kinds of data. Everything runs in your browser.

1. Where and what

This copy runs in a sandbox that cannot reach forecast services, so it works on synthetic sample data, a recorded real forecast, or your own CSV. The standalone demo adds live forecasts and place search.

2. The rules (editable plan)

This is the plan the engine runs. Hard constraints must hold for every hour of the window; soft preferences only rank the windows that pass. Values are in the engine's standard units (see the units list below). Edit anything and run again.
